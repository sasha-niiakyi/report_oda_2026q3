# Підсумки кварталу — презентація ОКР

Презентація результатів ОКР Сектору цифрового розвитку Одеської ОДА за III квартал 2026 року: ПРО.ШІ, ПРОЯВ, відкриті дані, Програма цифрової трансформації 2027–2029.

## Як відкрити

Відкрийте `presentation/index.html` у браузері (найкраще Chrome). Інтернет не потрібен: шрифти, картинки й відео лежать поруч у `presentation/assets/` і `presentation/fonts/`.

Переносити треба всю теку `presentation/` (без `versions/` і `variants/` можна).

## Керування

| Клавіша | Дія |
|---|---|
| `→` / пробіл / клік | наступний крок |
| `←` / правий клік | попередній крок |
| `1` `2` `3` `4` | перейти до проєкту: ПРО.ШІ · Програма · ПРОЯВ · Відкриті дані |
| `Home` / `End` | на початок / в кінець |
| `F` | на весь екран |
| `P` | вікно доповідача (поточна й наступна репліка, годинник, таймер) |
| `B` | чорний екран |
| `N` | показати номер кліку |
| `H` | довідка |

Один клік — одна репліка з тексту виступу. Відкрити з потрібного кліку: `index.html#22`.

## Текст виступу

`speech.md` збирається автоматично з презентації — не редагуйте його вручну.

1. Правте репліки в `presentation/index.html`, масив `window.NOTES` (одна репліка — один клік).
2. Запустіть:
   ```
   python3 presentation/tools/make_speech.py
   ```

## Структура

```
presentation/
  index.html        — презентація (слайди, стилі, скрипти, текст виступу)
  assets/           — скриншоти, відео ПРОЯВ, карта області, логотип
  fonts/            — шрифти
  tools/            — генератор speech.md
  versions/         — попередні версії презентації і виступу (не в git)
  variants/         — варіанти титульного слайда ПРОЯВ (не в git)
speech.md           — текст виступу
```

Карта області — межі громад з OCHA HDX COD-AB Ukraine.
